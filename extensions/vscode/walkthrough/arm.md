## Why a baseline

A verdict is a snapshot. A gate is a promise about the future.

Arming freezes the current behavior graph as accepted. Every later edit is compiled and compared
against it, so the interesting question stops being *"is this app secure?"* and becomes
**"did this change remove a guard, expose a route, or break an invariant?"** — which is a
question a machine can answer in the edit loop, deterministically and offline.

That loop is the point. An AI writes; SPARDA proves. Run
**SPARDA: Install the gate into Claude Code** to have every agent edit checked as it happens.
